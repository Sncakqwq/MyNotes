这套数据叫：

**XJTU-SY Bearing Dataset**

它是**西安交通大学 XJTU-SY 轴承数据集**，专门用于研究**滚动轴承的退化、故障诊断和剩余寿命预测（RUL）**。

最关键的一点：

**它不是“已经整理好的训练集”，而是轴承从正常运行一直运行到失效的完整实验数据。**

官方资料明确说，这套数据包含 **15 个滚动轴承的完整 run-to-failure 数据**。



# 一   **三种不同的实验工况**。

35Hz12kN
37.5Hz11kN
40Hz10kN

其实代表的是**三种不同的实验工况**

| 文件夹       | 转速     | 载荷  |
| ------------ | -------- | ----- |
| `35Hz12kN`   | 2100 rpm | 12 kN |
| `37.5Hz11kN` | 2250 rpm | 11 kN |
| `40Hz10kN`   | 2400 rpm | 10 kN |

官方实验设置就是这三个工况，每个工况测试 **5 个轴承**。

```c
35Hz12kN
├── Bearing 1_1
├── Bearing 1_2
├── Bearing 1_3
├── Bearing 1_4
└── Bearing 1_5

37.5Hz11kN
├── Bearing 2_1
├── Bearing 2_2
├── Bearing 2_3
├── Bearing 2_4
└── Bearing 2_5

40Hz10kN
├── Bearing 3_1
├── Bearing 3_2
├── Bearing 3_3
├── Bearing 3_4
└── Bearing 3_5
```



# 二 为什么每个 Bearing 里面有这么多 CSV

```c
Bearing_1_1
│
├── 1.csv
├── 2.csv
├── 3.csv
├── 4.csv
├── ...
└── 123.csv
```

实际上，它代表的是：**同一个轴承在不同时间点采集到的振动信号。**

官方资料明确说明：

​	每次采样得到的数据都会保存为一个 CSV 文件。

而且采样周期是：

​	**1 分钟采样一次。**

所以

```c
1.csv
↓
轴承运行第 1 分钟时采集的振动信号

2.csv
↓
轴承运行第 2 分钟时采集的振动信号

3.csv
↓
轴承运行第 3 分钟时采集的振动信号

...

123.csv
↓
轴承运行到后期时采集的振动信号
```



# 三  一个 CSV 里面到底是什么？

```c
Horizonal    Vertical_vibration_signals
-0.39639     -0.03867
-0.12311     -0.3659
0.988841     -0.58378
...
    
    
第一列：Horizontal vibration signals  // 水平振动信号
第二列：Vertical vibration signals    // 垂直振动信号
```



# 四  那么整个 Bearing_1_1 是什么



官方数据显示它有：

**123 个 CSV**

寿命：

**2 h 3 min**

```c
轴承开始运行
│
├── 1分钟 → 1.csv
│            └─ 32768个水平振动数据
│            └─ 32768个垂直振动数据
│
├── 2分钟 → 2.csv
│
├── 3分钟 → 3.csv
│
├── ...
│
├── 122分钟 → 122.csv
│
└── 123.csv
      ↓
    轴承最终失效
```

这就是所谓的：

​			**Run-to-Failure（从运行到失效）数据。**

这就是：

# **RUL —— Remaining Useful Life**

即：

**剩余使用寿命 / 剩余有效寿命**

# 五、为什么这些数据能预测寿命？

因为轴承从：

```c
正常
 ↓
轻微退化
 ↓
逐渐退化
 ↓
严重退化
 ↓
故障

它的振动特征通常也会发生变化。
```



你可以粗略理解成：

```c
轴承健康程度

100% ────────────────┐
                     \
                      \
                       \
                        \
                         \
                          ↓
0%  ─────────────────── 故障
       时间 →
    
而你的数据实际上记录了这个过程中：
    
            时间
             ↓
            振动信号
             ↓
            振动特征变化
             ↓
            轴承退化
             ↓
            最终故障
    
```

所以机器学习模型可以尝试学习：

​		**“振号的变化” → “轴承退化程度 / 剩余寿命”**
